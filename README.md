## 中文介绍

AKStream.Next 是面向视频监控、流媒体接入和实时音视频场景的视频管理平台。通过统一的设备、通道和录像管理，将视频接入、实时预览、录像回放、协议互通和业务系统集成连接起来。

- **多协议接入**：支持 GB28181、ONVIF、RTSP，以及常用流媒体播放与分发场景。
- **视频管理**：设备和通道管理、实时预览、录像计划、录像检索与回放、云台控制和视频墙。
- **智能检索**：按文字或参考图片检索已建立索引的视频内容；模型、硬件和功能要求请参阅文档。
- **实时音视频**：WebRTC 会话、音视频会议及 RTC SDK 接入。
- **业务集成**：公开 API、事件通知和 AI 对接 Skill，帮助业务系统接入视频能力。
- **多平台部署**：提供 Windows、Linux、macOS 和 Docker 发布包；实际架构与组件以对应 Release 为准。

## English introduction

AKStream.Next is a video management platform for surveillance, streaming integration, and real-time audio and video. It brings device and channel management, live viewing, recording and playback, protocol interoperability, and business integration into one product.

- **Protocol integration**: GB28181, ONVIF, RTSP, and common streaming playback and distribution workflows.
- **Video management**: devices and channels, live preview, recording schedules, recording search and playback, PTZ control, and video walls.
- **Intelligent search**: text and reference-image search over indexed video; see the documentation for model, hardware, and feature requirements.
- **Real-time communication**: WebRTC sessions, meetings, and RTC SDK integration.
- **Business integration**: public APIs, event notifications, and an AI integration Skill.
- **Deployment options**: Windows, Linux, macOS, and Docker packages. Supported architectures and included components are listed in each Release.
